💡 How to Test REST Endpoints via JSON:

Step 1 (Admin Login): Execute POST /auth/v1/token?grant_type=password with JSON body {"email": "...", "password": "..."} to receive your access_token.
Step 2 (Authorize): Click the green "Authorize" button at top right and paste your apikey and Bearer <access_token>.
Step 3 (CRUD via JSON): Use GET /rest/v1/products?select=* (Public Read), POST /rest/v1/products (Admin Create with JSON body), PATCH /rest/v1/products?id=eq.{id} (Admin Update with JSON body), and DELETE /rest/v1/products?id=eq.{id} (Admin Delete).
